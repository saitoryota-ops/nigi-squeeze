# にぎにぎスクイーズ屋（試作版）

スクイーズを長押しで握って、お客さんの注文どおりの強さで渡す60秒のスコアアタック。
ブラウザで遊べるWeb版の試作です。

- 遊ぶ：https://saitoryota-ops.github.io/nigi-squeeze/
- 進み具合はブラウザに保存されます（端末ごと）
- ジェムショップはテスト用で、押すとジェムが増えるだけです（お金はかかりません）
- ランキングのライバルは架空です

## ローカルで動かす

```
python serve.py 8884
```

## 絵の作り方

スクイーズ・背景・UIの絵はローカルの画像生成（ComfyUI + Anima）で作り、`tools/` のスクリプトで背景を抜いています。

- `tools/gen_squishy.py` … スクイーズを生成
- `tools/gen_ui.py` … 背景・お皿・アイコンを生成
- `tools/cutout.py` … 単色背景を抜いて透過PNGに
